# Rafael Cristóvão

**`Estagiário de TI · Desenvolvedor Web`**

Estudante de Análise e Desenvolvimento de Sistemas e estagiário de TI, com experiência prática em desenvolvimento back-end com PHP, JavaScript e SQL. No estágio, desenvolvo e mantenho regras de negócio, integro APIs de inteligência artificial (Claude/Anthropic) a chatbots, analiso consumo de tokens para reduzir custos e faço auditorias e validações de dados com SQL e JSON, sempre com versionamento em Git e GitHub. Fora do trabalho, construo projetos pessoais como o Painel-rotina, um sistema de hábitos, treino e sono que une automações no iPhone com um painel web em React e TypeScript. Também tenho experiência com Node.js, Express e MongoDB, e busco evoluir continuamente em boas práticas e na construção de soluções eficientes e confiáveis.
